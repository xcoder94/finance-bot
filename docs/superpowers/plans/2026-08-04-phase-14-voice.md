**Goal:** Accept Telegram voice messages, transcribe them via Google Cloud Speech-to-Text, and feed the resulting text through the exact same quick-entry pipeline as typed messages — typing indicator only, transcription never shown.

Voice handler: set typing immediately → download OGG → transcribe → empty/None → §9 text + `spend_unparsed`; otherwise call the shared core (which already spends 1 model call per message for N operations).

**Tech Stack:** Python, httpx, Aiogram 3, FastAPI bot path, pytest. No new packages. Backend only — frontend untouched (must stay 205 tests / 37 files).

## Shared-pipeline decision (locked before coding)

**Chosen approach:** Extract the body of `handle_quick_entry_text` (everything after reading/stripping `message.text`) into:

```python
async def process_quick_entry_text(message: Message, bot: Bot, text: str) -> None:
    ...
```

- `handle_quick_entry_text` becomes: validate `message.from_user` / `message.text` → strip → empty return → `await process_quick_entry_text(message, bot, text)`.
- Voice path transcribes to a Python `str`, then calls the same `process_quick_entry_text`. It never builds cards or spends model/unparsed counters for parse outcomes itself (except the voice-only not-recognised path before the shared core runs).
- Do **not** duplicate parse/classify/counter/card loops in the voice handler.

## Speech API surface (Google Cloud Speech-to-Text v1 — do not invent)

Base: `https://speech.googleapis.com/v1/speech:recognize?key={SPEECH_API_KEY}`

Request body:

```json
{
  "config": {
    "encoding": "OGG_OPUS",
    "sampleRateHertz": 48000,
    "languageCode": "ru-RU",
    "model": "<SPEECH_MODEL from env, never hard-coded>"
  },
  "audio": {
    "content": "<base64 of downloaded Telegram voice bytes>"
  }
}
```

Success transcript: join `results[*].alternatives[0].transcript` with spaces, strip. Empty results / blank transcript → not recognised.

HTTP / JSON failure → raise `SpeechUnavailable` (mapped like parser unavailability to `MSG_MODEL_FAIL`, **without** spending unparsed — our side failed, not the person's speech).

Telegram voice messages are OGG Opus; 48000 Hz is the Telegram default. If live acceptance later shows a sample-rate mismatch, that is a follow-up — do not invent auto-detection in this phase.

**Auth note:** `SPEECH_API_KEY` mirrors `PARSER_API_KEY` (query `key=`). Classic GCP often prefers ADC; this phase follows the project's existing API-key pattern. If live keys later require a different auth scheme, stop and ask — do not silently switch.

`backend/app/speech/google_client.py`:

```python
from __future__ import annotations

import base64
import logging
from typing import Any

import httpx

from app.speech.base import SpeechUnavailable

logger = logging.getLogger(__name__)

_RECOGNIZE_URL = "https://speech.googleapis.com/v1/speech:recognize"
_TIMEOUT_SECONDS = 30.0


class GoogleSpeechClient:
    def __init__(self, api_key: str, model: str) -> None:
        self._api_key = api_key
        self._model = model
        self._http = httpx.AsyncClient(timeout=_TIMEOUT_SECONDS)

    async def transcribe(self, audio: bytes) -> str:
        params = {"key": self._api_key}
        body: dict[str, Any] = {
            "config": {
                "encoding": "OGG_OPUS",
                "sampleRateHertz": 48000,
                "languageCode": "ru-RU",
                "model": self._model,
            },
            "audio": {"content": base64.b64encode(audio).decode("ascii")},
        }
        try:
            response = await self._http.post(_RECOGNIZE_URL, params=params, json=body)
        except httpx.HTTPError as exc:
            raise SpeechUnavailable("speech transport failed") from exc
        if response.status_code >= 400:
            raise SpeechUnavailable(f"speech HTTP {response.status_code}")
        try:
            data = response.json()
        except ValueError as exc:
            raise SpeechUnavailable("speech response is not JSON") from exc
        return _extract_transcript(data)


def _extract_transcript(data: Any) -> str:
    if not isinstance(data, dict):
        raise SpeechUnavailable("speech response is not an object")
    results = data.get("results") or []
    if not isinstance(results, list):
        raise SpeechUnavailable("speech results malformed")
    parts: list[str] = []
    for item in results:
        if not isinstance(item, dict):
            continue
        alts = item.get("alternatives") or []
        if not isinstance(alts, list) or not alts:
            continue
        first = alts[0]
        if isinstance(first, dict):
            t = first.get("transcript")
            if isinstance(t, str) and t.strip():
                parts.append(t.strip())
    return " ".join(parts)
```

    if file.file_path is None:
        await message.answer(MSG_MODEL_FAIL)
        return
    buffer = await bot.download_file(file.file_path)
    audio = buffer.read() if hasattr(buffer, "read") else bytes(buffer)

    try:
        transcript = await _get_speech_client().transcribe(audio)
    except SpeechUnavailable:
        await message.answer(MSG_MODEL_FAIL)
        return

    text = transcript.strip()
    if not text:
        telegram_id = message.from_user.id
        async with async_session_factory() as session:
            user = await get_active_user_by_telegram_id(session, telegram_id)
            if user is None:
                await message.answer(MESSAGES["not_registered"]["ru"])
                return
            budget = await session.get(FamilyBudget, user.family_budget_id)
            if budget is None or budget.is_deleted:
                await message.answer(MESSAGES["not_registered"]["ru"])
                return
            today = tashkent_today_for_counters()
            ensure_counters_day(budget, today)
            if not can_unparsed(budget, DAILY_UNPARSED_LIMIT):
                await message.answer(unparsed_limit_text(DAILY_UNPARSED_LIMIT))
                await session.commit()
                return
            spend_unparsed(budget)
            await session.commit()
            await message.answer(MSG_VOICE_NOT_RECOGNIZED)
        return

    await process_quick_entry_text(message, bot, text)
