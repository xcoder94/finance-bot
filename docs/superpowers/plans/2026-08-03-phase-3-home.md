# Phase 3 — Mini App Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Worker model:** `composer-2.5` only. Do not substitute.

**Goal:** Open the mini app and see Home matching design form + PRD meaning: budget name, role line, month/currency filters, shared figures, action buttons, recent ops (empty/skeleton states), four-tab bottom menu with `Цели` instead of `История`.

**Architecture:** Backend adds `FamilyBudget.name` (default `Семейный бюджет`) and extends `/me` with `budget_name` + `member_count`. Wallet balances (and summary inputs for Home) count **shared wallets only**. Frontend rebuilds Home layout to match `docs/design/Chontak MVP2.dc.html` L59–L158 (not `Мои личные`), swaps tabbar History→Goals shell, adds vitest for pure helpers. Action buttons keep MVP1 routes `/add-income|expense|transfer`. No rename UI. No Goals CTAs. No dead controls.

**Tech Stack:** Python/FastAPI/Alembic/pytest; React/Vite/TypeScript/TelegramUI/Zustand/react-i18next; vitest for frontend unit tests; design file `docs/design/Chontak MVP2.dc.html`.

## Global Constraints

- Spec: `docs/tasks/phase-03-home.md` + PRD §17.1–§17.2, §5 + **customer addendum (2026-08-03)** for Home form/name (do not edit `docs/PRD.md`).
- Design path: `docs/design/Chontak MVP2.dc.html` (space in filename). Form = design; meaning = PRD.
- Layout: design L62–77 (name+role | currency same row; month bar below). Figures: design L106–120 (Остаток hero, then Доход|Расход).
- `monthShort` exact: `янв · фев · март · апр · май · июнь · июль · август · сен · окт · ноя · дек` (design L922).
- Role line: owner `Общий бюджет · {n} · вы владелец`; member without suffix. Plural via i18next: 1 участник / 2 участника / 5 участников.
- Empty month (exact): title `В {prep} операций нет`; hint `Напишите боту «такси 32000» — операция появится здесь.` Ops count: `нет операций` or `{n} за {monthShort}`.
- Budget name: VARCHAR(30) NOT NULL default `Семейный бюджет`; backfill; `/me` returns it; never «Мои финансы»; no rename UI; no Telegram-derived names.
- Currency switch = filter only; never convert; never use prototype rate 12650.
- Bottom menu exactly: `Главная` · `Аналитика` · `Цели` · `Настройки`. No floating `+`. No History tab. History remains reachable via «Последние операции ›».
- Dead controls: do not render Goals create/tabs, rename, or `Мои личные`. Goals page = title only (or empty content without CTAs).
- Action buttons shown and wired to existing MVP1 add forms (they work).
- Transfer/exchange in recent list: neutral colour, no minus, `↔` prefix per design.
- Shared figures only (`is_personal = false`). Personal wallets Phase 7.
- Theme: Telegram theme vars; light/dark equal; map design tokens; no hard-coded light-only Home.
- Worker: `composer-2.5` only. Branch: `mvp2/phase-3-home`. Do not edit `docs/PRD.md` / `AGENTS.md`.
- Report pytest + frontend vitest/build before/after; list stubs.
